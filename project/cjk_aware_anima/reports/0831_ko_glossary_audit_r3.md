# KO glossary — review round 3 (collisions + the tail below the review floor)

*2026-08-31, after the K1.5 round-2 sign-off and the K2 joint retrain. CPU
only. Corpus rebuilt; `cache_ko` and `cjk_vocab_pack_synthjako` are now stale
against it — see "What this owes".*

## Why a round 3

`tag_glossary_review_ko.md` is the top-200 **disagreement** table: rows where
the wiki idiom and the MT rendering differ, sorted by occurrence. Rounds 1–2
worked that file to exhaustion. Two surfaces survive it by construction:

1. **Collisions.** The table is per-tag, so it cannot show that two different
   EN tags were handed the *same* KO wording. Each row reads fine alone while
   the pair collapses two concepts onto one set of ext rows — the exact
   discrimination the pack is trained to buy.
2. **The tail below the floor.** 200 rows bottomed out at n=454, i.e. 43.8 %
   of occurrences. The remainder was 14,827 tags / 252,568 occ, of which
   `mt_unverified` — the tier no automatic source ever confirmed — was
   4,416 tags / 82,502 occ.

Both are now generated by `datasets/audit_glossary.py` (read-only over a built
glossary, lang-agnostic):

    python project/cjk_aware_anima/datasets/audit_glossary.py --lang ko

→ `assets/collisions_ko.md` and `assets/tag_glossary_review_ko_tier2.md`.

## What the audit found

**Collisions.** 336 raw groups over 103,594 occ (15 % of the corpus). Folding
orthographic variants (`white shirt`/`white shirts`, `gray`/`grey`) and
long-tail rivals (`1girl` vs a 2-count `o o`) left **93 groups / 63,040 occ**
needing a decision. Representative:

| n | target | members | verdict |
|--:|---|---|---|
| 4135 | 엉덩이 | `ass` + **`abs`** | not a collision — `abs` was mistranslated (복근) |
| 2218 | 리본 | `bow` + `ribbon` | **accepted** — synonyms in Korean (user) |
| 1638 | 교복 | `school uniform` + `serafuku` | split — the plan's named 세라복/세일러복 axis |
| 6937 | 거유 | large / huge / hanging / pointy breasts | split — one word for four sizes |
| 4644 | 미소 | smile + grin + smirk | split |
| 2209 | 침대 | `on bed` + `bed` | split — position vs object |

**Tail.** Errors start immediately below the floor: `paizuri` → 포즈
("pose"), `panty pull` → 팬티 풀러, `cuffs` → 손목찌개 ("wrist stew"),
`hair intakes` → 머리 잡아당김 (a hairstyle read as an action), `dated` →
구식 (the danbooru tag means a date is written on the image), `aqua eyes` →
수색 눈동자 ("searching eyes"), `yuri` → 유리 ("glass"), `pool` → 풀
(collides with `grass`).

**Comma hazard.** 63 wordings contained a comma or period. Two carry real
traffic — `pov crotch` → `시점, 사타구니` (369) and `top-down bottom-up` →
`위에서 아래로, 아래에서 위로` (236) — and a comma inside a wording re-splits
into two tags when the caption is composed. Both fixed.

A third, smaller finding needs no glossary action: **60 tags in the caption
index are position-clause fragments** (`thighs.`, `weight. On the left`,
`spread legs.`), 265 occ, and they are present in the JA glossary too. That is
a caption-master split that did not honour the position-clause grammar, not a
KO issue.

## Round 4 (same day) — user vetoes + the emoticon tags

Eight user corrections applied: `imminent vaginal` → 삽입 직전, `aqua eyes` →
아쿠아색 눈, `breasts apart` → 벌어진 가슴, `petite` → 키작은,
`toenail polish` → 발가락 네일, `hair scrunchie` → 머리 고무줄 (`heart censor`
→ 하트 검열 and `cuffs` → 수갑 already stood). `imminent penetration` moved to
삽입 임박 so it does not collide with the new `imminent vaginal` wording, and
the now-stale 머리끈 row was dropped from the accepted-merge ledger.

The user's question about a `:소녀 1명` wording turned up a small class the
audits had not isolated: **emoticon face tags eaten by MT**. `:d` `:o` `:q`
`:3` `:p` came back `mt_verified` and stayed latin as the standing rule says,
but the `mt_unverified` ones did not — `:t` (29), `:s` (2), `:i` (2) all read
`:소녀 1명`, and `:c` (2) read `:커플`; `:&gt;` had become `&gt;&gt;`. All
five pinned back to their literal form.

Still open, same class, not yet applied (25 occ): five character tags whose
**copyright suffix was translated literally** —
`hulkenberg (metaphor: refantazio)` → 훌켄베르크 (**비유**: 리파인트),
`astral express (honkai: star rail)` → 아스트랄 익스프레스 (**홍해**: 스타
레일). The pinned-name convention drops the parenthetical entirely
(`firefly (honkai: star rail)` → 반디), so the fix is to pin the bare name.

Chain re-run; overrides **345**, occurrence share 16.1 %, collision groups
still 3, coverage gate green and unchanged.

## What this owes

263 tags changed wording, 43,336 occ = **6.39 % of the corpus**, and by exact
segment match **41,107 of 62,480 pairs (65.8 %)** now carry different student
text (`names_ko` is nearly untouched at 2.9 % — it is EN context plus KO names;
`tags_ko`/`tags_alt_ko`/`names_synth_ko` are ~88 %).

content, so there is **no incremental restage**: `cache_ko` (44 GB) has to be
re-staged in full and `2c-synthjako` retrained (~45 GPU-min) before the K3
gates mean anything about the shipped wording. The K3 metric readouts and the
three grids in `plan_ko.md` describe the **round-2** corpus.

grids, and gate 5 (register drift, 300 hand-typed prompts) is owed regardless.
